# 引用とコードブロックの逐語保持（2026-09-05）

**種別: アイディアドキュメント（記録）。正本ではない。**
書かれた時点の事実であり、**現在の仕様として読まないこと。**
仕様の正本は `docs/design/data-format.md` 6.3 と 6.4。

---

## なぜやったか

**`.md` が正本（Single Source of Truth）である。** ベンダーロックインを避けることが
このツールの中心にある。開いて保存しただけで他人の書いたものが消えるなら、
`.md` は正本ではなくなる。

2026-09-04 まで、引用とコードブロックは警告を積んで**丸ごと破棄**されていた。

```
- 枝
  > 引用文          →  「箇条書き内の blockquote は変換できないため破棄しました。」
                       出力は「- 枝」だけ
```

前日に直したエスケープの取りこぼしと**同じ入口の、同じ種類の損失**である。

## 判断の基準

**エスケープするのは「木の形を変えるもの」だけにする。**
ノートの中の形しか変えないものは逐語で出す。

| ノート行の頭 | 逐語で出すと | 扱い |
|---|---|---|
| `#` `- ` `1. ` `---` `<` `[a]:` | 子ノードや見出しになる＝**木が変わる** | エスケープする |
| `>` 柵 半角4つ | ノートの中の形しか変えない | **逐語で出す** |

判断は `src/core/note.ts` に集め、保存側・読み込み側・表示側が同じ関数を使う。
**別々に判断すると「保存はできているのに画面に出ない」食い違いが起きる。**

## 実測して決めたこと

**測らずに書いた設計は3箇所で外れた。** 全て `remark-parse` に実際に食わせて確かめた。

| 測ったこと | 結果 | 設計への反映 |
|---|---|---|
| 閉じない柵の後ろに `- 子` を置く | **`- 子` がコードの中身になり、枝が1本消えた** | 対の無い柵はエスケープして文字にする |
| 柵をラベル行の直後に置く | コードになる（段落を中断できる） | 空行は要らない |
| インデントコードをラベル行の直後に置く | **段落に吸われて消える** | ラベルの直後なら空行を挟む |
| `> q` の次行に `lazy` | 同じ引用の中身になる（遅延継続行） | 読み込み時に全行を `>` 始まりへ揃える |
| 段落の次行に `> q` | 別のブロックになる | 塊の境目に空行を入れる |

## 分かれ道：既存の `\>` をどう読むか

いまノートに `>` で始まる行を書くと、ファイルには `\> q` と保存されている。
規則を変えると、この `\` の意味が問題になる。

| | 他人の `.md` の `\> q` | 過去に保存したマップ |
|---|---|---|
| **A（採用）** | **文字のまま。安全** | ノート編集欄に `\` が見える。**表示は正しい** |
| B | **引用に化ける。他人のファイルを書き換える** | きれいに移行する |

**A を採った。** 「`.md` が正本」から直接出てくる帰結であり、
前日に直したばかりの「他人が書いたバイト列を動かさない」を自分から破らないため。

実装は「外す判定をノート全体で行う」（`note.ts` の `unescapeNote()`）ことで
自動的に正しくなる。`\> q` は外すと引用になってしまうので外れず、
対の無い `` \``` `` は外してもファイル上のバイト列が動かないので外れる。

## ついでに見つかったもの

**リンク参照定義が行をまたぐと枝が丸ごと消える。**
ラベル `[` ＋ノート `!]:` が `definition` として解析され、ノードごと破棄されていた。
**変更前のコードでも同じであることを実測で確かめた**（今回持ち込んだものではない）。
行頭エスケープの取りこぼしなので、同じ関数に1行足して塞いだ。
25万件のプロパティテストが 14,489 件目で見つけた。

## まだ破棄されるもの（未着手）

**`.md` が正本である以上、これらも本来は残すべきである。** 頻度を測っていない。

| 要素 | どうなるか |
|---|---|
| 水平線（`---` `***`） | 破棄。警告は出る |
| HTML ブロック（`<div>`）| 破棄。警告は出る |
| 箇条書き内の見出し | 破棄。**`- 枝` の次行が `---` だと setext 見出しになり、ラベルごと消える** |

水平線と HTML は「ノートへ逐語で入れてエスケープする」で塞げる見込みだが、
`\---` `\<div>` とファイルが書き換わる（内容は残るがバイト列は動く）。
**逐語で出せない以上、どちらを取るかの判断が要る。**
