# 空ラベルの入れ子で往復が揺れる（2026-09-05・解決済み）

**種別: アイディアドキュメント（記録）。正本ではない。**
書かれた時点の事実であり、**現在の仕様として読まないこと。**

**エスケープの往復を直す作業（同日）の途中で見つかった別件である。**
変更前のコードでも同じように揺れることを実測で確かめてあり、
**今回の修正が持ち込んだものではない。**

---

## 症状

`- *` `- -` `- +` のように、**箇条書きの中身が箇条書き記号1つだけ**の行を開くと、
1周目と2周目で形が変わる。

```
入力    # 根

        - *

1周目   # 根

        -

          -

2周目   # 根

        -

        -
```

1周目は「空のラベルの下に空のラベル」、2周目は「空のラベルが2つ並ぶ」。
**親子だったものが兄弟になる。** 3周目以降は安定する。

## なぜ起きるか

`serialize.ts` は空ラベルの箇条書きの前に空行を入れる。CommonMark では
空の箇条書きが段落を中断できず、直前の行の遅延継続行として吸収されてしまうためで、
これ自体は必要な規則である（`docs/design/data-format.md` 6.4）。

**ところがその空行が、入れ子の親子関係も切ってしまう。**
`-` と `  -` の間に空行があると、`  -` は子ではなく兄弟として解析される。

## どこまで確かめたか

| 入力 | 揺れるか |
|---|---|
| `- *` `- -` `- +` | **揺れる** |
| `- `（空） | 安定 |
| `- a` | 安定 |
| `- * b` | 安定 |
| `- **` | 安定 |
| `- *a*` | 安定 |

**中身が空になる入れ子だけである。** 親か子のどちらかに文字があれば起きない。

## 影響

**ラウンドトリップの強保証（設計原則5）の破れである。** ただし到達経路は狭い。

- **自分で作ったマップでは起きない。** 空のラベルの下に空のラベルを作る操作が要る
- 他人が書いた `.md` に `- *` のような行があると踏む。**2周目以降は安定する**ので、
  失われるのは「親子だった」という構造1つぶんである

`src/core/__tests__/foreign-file.test.ts` の性質テストは、この形を明示して除外している。
**除外の理由をコードのコメントにも書いてある。**

## 決着（2026-09-05）

**CI が落ちて分かった。** 乱数の種次第で `roundtrip.test.ts` が落ちる状態になっており、
1,581 件目で反例を引いた。**頻度を測ってから直すつもりだったが、
測る前に「全ての PR を止める」という形で実害が出た。**

**原因は空行の入れ方だった。** 空の箇条書きの前に空行を入れる規則は、
「直前の段落に吸われる」のを防ぐためのものである。ところが**直前も空の箇条書きなら、
続ける先の段落がそもそも無い。** 要らない空行が入れ子だけを切っていた。

実測して条件を切り分けた。

| 直前の行 | 空の `-` の前に空行が | 結果 |
|---|---|---|
| `- 枝`（段落）で、空の `-` が深い位置 | **要る** | 無いと吸われてノードごと消える |
| `- 枝`（段落）で、空の `-` が同じ位置 | どちらでもよい | 兄弟になる |
| `-`（空の箇条書き） | **入れてはいけない** | 入れると入れ子が切れる |

直したのは `serialize.ts` の1行で、**直前が空の箇条書きなら空行を入れない**。

**`foreign-file.test.ts` の除外を外した。** 外したまま 25 万件を通している。

## 教訓

- **「頻度を測ってから直す」は、実害の出方を測れているとは限らない。**
  利用者が踏む頻度は低くても、**乱数を回す仕組みが先に踏む**
- 稀に落ちる性質テストを見たら、**まず反例かタイムアウトかを見分ける。**
  今回はタイムアウトが2件混ざっており、そちらは上限を上げるだけで済んだ
