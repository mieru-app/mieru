## 症状

`- *` `- -` `- +` のように、**箇条書きの中身が箇条書き記号1つだけ**の行を開くと、
1周目と2周目で形が変わる。

```
入力    # 根

        - *

1周目   # 根

        -

          -

2周目   # 根

        -

        -
```

1周目は「空のラベルの下に空のラベル」、2周目は「空のラベルが2つ並ぶ」。
**親子だったものが兄弟になる。** 3周目以降は安定する。

## なぜ起きるか

`serialize.ts` は空ラベルの箇条書きの前に空行を入れる。CommonMark では
空の箇条書きが段落を中断できず、直前の行の遅延継続行として吸収されてしまうためで、
これ自体は必要な規則である（`docs/design/data-format.md` 6.4）。

**ところがその空行が、入れ子の親子関係も切ってしまう。**
`-` と `  -` の間に空行があると、`  -` は子ではなく兄弟として解析される。

## どこまで確かめたか

| 入力 | 揺れるか |
|---|---|
| `- *` `- -` `- +` | **揺れる** |
| `- `（空） | 安定 |
| `- a` | 安定 |
| `- * b` | 安定 |
| `- **` | 安定 |
| `- *a*` | 安定 |

**中身が空になる入れ子だけである。** 親か子のどちらかに文字があれば起きない。

## 影響

**ラウンドトリップの強保証（設計原則5）の破れである。** ただし到達経路は狭い。

- **自分で作ったマップでは起きない。** 空のラベルの下に空のラベルを作る操作が要る
- 他人が書いた `.md` に `- *` のような行があると踏む。**2周目以降は安定する**ので、
  失われるのは「親子だった」という構造1つぶんである

`src/core/__tests__/foreign-file.test.ts` の性質テストは、この形を明示して除外している。
**除外の理由をコードのコメントにも書いてある。**

## 直すときに考えること

**空行を入れずに空の箇条書きを表現する方法が要る。**
候補は「空ラベルの親には子を持たせない（子を持つなら何か文字を入れる）」だが、
それは利用者の構造を勝手に変えることになる。

**先に、この形が実際に現れる `.md` がどれくらいあるかを測ること。**
測らずに直すと、狭い経路のために正規化規則を1つ増やすことになる。
エスケープの往復（同日）は OSS 配信で頻度が100%になったから直した。
**こちらは頻度が分かっていない。**
