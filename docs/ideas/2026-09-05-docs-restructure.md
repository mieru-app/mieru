## 3. README の骨子

```
# Mieru
一行の説明。スクリーンショット 1 枚（マップと .md を並べたもの）。公開 URL。

## こんな困りごとに
- AI に相談したいが、考えが整理されていない → 整理した形がそのまま入力になる
- マインドマップを描いても、書き出すと崩れる・他のツールで開けない → 保存形式が .md
- ノート（Obsidian / VS Code）とマップを二重に管理している → 同じファイルを両方で開く

## 使い方
1. 開く  2. 保存先を選ぶ（このパソコン／GitHub）  3. Tab と Enter で書く  4. .md を AI に渡す

## 活用ケース
企画の論点整理／読書・学習メモ／Obsidian の vault 内で／スマートフォンで思いつきを GitHub に溜める

## よくある疑問
データはどこにあるか・誰が見られるか／トークンは何に使うか／オフラインで使えるか／
対応ブラウザ／他のツールで書いた .md は開けるか（エスケープの課題を正直に書く）

## 開発に参加する → CONTRIBUTING.md
## ライセンス
```

セキュリティの詳細は `docs/design/security.md` へ移し、README は要約と参照に留める。
英語版は後続（マーケティング調査の提案どおり）。**先に日本語で構成を固める。**
