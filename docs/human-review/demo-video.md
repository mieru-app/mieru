# 30秒の動画の台本

**読者: 撮影する人。** 何を映すか、何を映してはいけないか、どの順で操作するか。

**この動画で伝えたいことは1つだけである。**

> **保存されるのは普通の `.md` であり、他のツールでそのまま開いて直せる。**

機能の紹介ではない。**「乗り換えても持ち出せる」ことを目で見せる**のが目的である
（狙う相手と理由は `docs/ideas/2026-09-05-stp-and-marketing.md`）。

| ファイル | 用途 |

どちらも **Mieru が出力する正規化済みの形**にしてある。開いて保存しても
1バイトも変わらないことを実測で確かめてある。**題材を差し替えるときは、
必ず開いて保存し、`git diff` が空であることを確かめること。**
差分が出る素材を使うと、**動画の主張そのものが崩れる。**

## 撮れたもの

[`assets/demo/demo-video.mp4`](../../assets/demo/demo-video.mp4)（2026-09-06）。
21.6秒・1920×1080・H.264・1.9 MB。画面は英語で、素材も英語版を使っている。

**字幕は日本語と英語を同時に焼き込んである**（上に日本語、下に英語）。
**1本で Show HN・Obsidian フォーラム・Zenn のすべてに出せる。**
言語ごとに書き出し分ける必要はない。

**音声トラックは残っているが無音である**（編集側でクリップを消音してあり、
AAC が無音を符号化しているだけ）。0.5 MB あるので、
`ffmpeg -i in.mp4 -c:v copy -an out.mp4` で外せば軽くなる。映像は再エンコードされない。

**README へは相対パスで貼れない。** GitHub はリポジトリ内の `.mp4` を再生せず、
相対パスはただのリンクになる。**Issue か Pull Request のコメント欄へファイルを
ドロップし**、得られた `https://github.com/user-attachments/assets/...` の URL を貼る。

**貼る形は「行に URL だけ」にする。** 角括弧のリンク記法で包むと
**ただのリンクへ落ちて、再生できなくなる。**
いま README で使っているのは `bb92dee9-08e8-4d18-8c9b-8695f3bf38ac`
（[PR #13](https://github.com/mieru-app/mieru/pull/13) へのドロップで作った）。

**再生されるのは github.com だけである。** npm・IDE のプレビュー・ミラーでは
リンクにしか見えないので、README では**下に1行の説明を添えてある。**

## 撮る前の準備

**IMPORTANT: 保存先はローカルフォルダにする。** GitHub 接続では外部変更の監視が無く
（設計 8.7.6）、後半が成立しない。

- **空のフォルダを新しく作り、素材を1つだけ置く。**
  一覧に他のマップ名が映ると、**自分のファイル名が公開される**
- ブラウザは Chrome か Edge。File System Access API が要る
- ブラウザのプロファイルを新規にするか、ブックマークバーを隠す
- **ノート欄を閉じておく。** 開いたままだとキャンバスが狭くなる（実測で 147px まで縮んだ）
- **表示言語を確かめる。** 既定は英語である。**画面ごと日本語で撮るときだけ設定で日本語へ切り替える。**
  切り替え忘れると、日本語の素材に英語のボタンが並ぶ
- エディタ（VS Code など）は**同じフォルダを開いた状態で待機**させる。
  拡張機能の通知やサイドバーの他ファイルが映らないようにする
- 画面は 1280×720 以上。**文字が読めない動画は伝わらない**

## 台本

**通しで撮らなくてよい。** 4つに分けて撮り、後で繋ぐ。特に③→④の待ち時間は必ず切る。

**字幕は日本語と英語を同時に出す**（上に小さく日本語、下に大きく英語）。
下の各節に並ぶ2行は、言語ごとの版ではなく**同じ場面に重ねる2行**である。

**字幕は3枚だけにする。** ②の場面には字幕を置かない。
そこは**画面そのものが Markdown を映しており、文字を重ねると読む対象が2つになる。**

### ① 図として編集する（0:00-0:08）

| 操作 | 映るもの |
|---|---|
| マップを開いた状態から始める | 中心テーマと3本の枝 |
| `What decides it` の枝を掴んで `What can it do?` の**上**へ落とす | 枝が動く |

**字幕:** `Think in a diagram.`（`図で考える`）

**やらないこと:** 拡大縮小・パン。**動きを1つに絞る。** 2つ入れると何を見ればよいか分からなくなる。

### ② 保存形式が `.md` であることを見せる（0:08-0:16）

| 操作 | 映るもの |
|---|---|
| `Ctrl+E` を2回押す | キャンバス → アウトライン → **Markdown 表示** |
| 少し止める | **①で動かした順序が、そのまま Markdown に出ている** |

**字幕:** 置かない（上の「台本」を見よ）。

**ここが動画の中心である。** 「順序を変えた」ことと「Markdown の行順が変わった」ことが
**同じ画面で繋がる**ように、①の操作結果が見える位置まで送っておく。

### ③ 他のツールで開く（0:16-0:24）

| 操作 | 映るもの |
|---|---|
| エディタへ切り替え、同じ `.md` を開く | **Mieru の Markdown 表示と同じ中身** |
| `What decides it` の下に1行足す | `  - How we get the notes out if we stop` |
| 保存する | — |

画面ごと日本語で撮る場合に足す行: `  - やめるときにメモをどう取り出すか`

**字幕:** `Edit it anywhere.`（`どこで直してもいい`）

**IMPORTANT: 半角スペース2つのインデントを守る。** ここを間違えると階層が変わり、
④で「意図した場所に枝が増えない」。

### ④ 戻ってくる（0:24-0:30）

| 操作 | 映るもの |
|---|---|
| Mieru へ切り替える | 上部に **`This file changed outside Mieru.`** のバナー |
| ［Reload it］を押す | **枝が1本増える** |

**字幕:** ここで `It's just Markdown.`（`保存されるのは .md`）を出す。

**当初は4枚目として `Your file stays yours.` を置いていたが、外した。**
②「保存形式は `.md`」と③「他のツールで直せる」で同じことを既に言っており、
**4枚目は言い換えにしかならない。** 字幕は少ないほど1枚あたりが読まれる。

**IMPORTANT: バナーは最大30秒待たないと出ない**（`LocalFolderStore` の監視間隔）。
**壊れているのではない。** 待っている間は撮らず、出てから撮って繋ぐ。

**間に合わないときの代替:** 一覧で別のマップへ切り替えて戻すと、その場で読み直される。
ただし**バナーは出ない。** バナーは「勝手に上書きしない」ことを見せる場面なので、
**待てるなら待つ方がよい。**

## 撮った後

- **音は入れない。** 字幕だけにする。吹き替えが要らず、
  **言語を変えるときも同じ録画に字幕を焼き直すだけで済む**
- **編集側でクリップを消音しても、書き出しには音声トラックが残る。**
  実測で 21.6秒に 518KB を占めていた。**無音なので害は無いが、耳では気付けない。**
  外すなら `ffmpeg -i in.mp4 -c:v copy -an out.mp4`
- 長さは30秒以内。**超えたら①を削る**（②③④が主張の本体）
- 形式は GIF ではなく MP4。GIF は文字が潰れる。README には MP4 を貼る
- **貼る前に自分で1回通して見る。** 文字が読めるか、他人のファイル名が映っていないか

## 映してはいけないもの

**IMPORTANT: 公開するとファイル名は消せない。**

- 一覧に並ぶ**自分の他のマップ名**
- ブラウザのタブ・ブックマーク・拡張機能
- エディタのサイドバーに並ぶ**他のファイル**
- GitHub 接続画面（**トークンの一部が映る**）
- 通知（Slack・メール）
