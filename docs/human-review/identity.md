# 名前・アイコン・ロゴ

**読む人: 見た目や名乗り方に関わる変更をする人。**
なぜこの名前とこの形なのかを残す。決定は Phase 2 着手時と Phase 2.5。

### 12.5 名称: Mieru（Phase 2 着手時に確定）

「見える」＝「考えが見えるようになる」で、名前と道具の価値が一致する。3音で呼びやすい。既存の同名ソフトはあるが全て別カテゴリ（プロキシ、OCR、通訳）で、マインドマップ領域には無い。

**綴りに `me` と `u` が含まれる（2026-09-02、文字ロゴの選定時に確認）。** 「見える」の目的語が自分（me）と相手（you）であり、本ツールはその2つのあいだで思考を繋ぐ、という読み方ができる。文字ロゴはこれを塗り分けにしている（12.7）。

不採用: **OpenMind.md** ——同じマインドマップ領域に既存の OpenMind が複数実在する（Microsoft Store 等）。**MDMind** ——識別性は最高だが `MD` の第一想起が Medical Doctor で響きが弱い。

**残る懸念:** ホワイトボードツール Miro と英字表記で1文字違い。日本語では明確に異なるが、一般公開時は混同の可能性を考慮する。

**商標（2026-09-02 調査）:** J-PlatPat に「MIERU」の出願が1件（商願2025-122872、**登録ではなく審査中**、株式会社コラボフィット）。ただし指定商品は第9類の**眼鏡類のみ**（類似群 10B01・23B01）。第9類は眼鏡からソフトウェアまでを含む広い区分であり、類否は類似群コードで判断される。ソフトウェアの 11C01 も第42類の 42X11 も含まれないため、**本ツールとは抵触しない**。

> カタカナ「ミエル」・平仮名「みえる」および第42類は未調査。個人利用と無償配布の範囲では商標権が及ばない（業としての使用に及ぶ）が、収益化する場合は着手前に弁理士による調査を行うこと。

### 12.6 アイコン: 「放射する光条」（Phase 2 着手時に確定）

文字マーク「M」を白抜きにして暗い地の中心に置き、その外側から5色の光条を放射させる。中心から枝が伸びるというマインドマップの構造がそのまま図案になっている。生成は `assets/icon/generate.mjs`（SVG と PNG を `assets/icon/dist/` へ書き出す）。

**最初の案が失敗した理由を規則として残す。** 白い M を載せるために5色すべての明度を揃えた結果、輝度が 10.7〜17.8% に収まり、隣り合う面のコントラスト比が 1.06〜1.29:1 になった。**色相が違っても明るさが同じ色は互いに見分けられない**（等輝度）。色は付いているのに境界が消え、濁って見える。

| 規則 | 理由 |
|---|---|
| 明るさの役割を分ける。地は徹底して暗く、色は地の上に置く | 白抜きの文字と鮮やかな色を両立させる唯一の方法。地と白の比 19:1、地と色の比 4.2:1 以上 |
| 色どうしを直接隣接させない。あいだに地を挟む | 境界のコントラストが常に高くなり、等輝度の隣接を構造的に避けられる |
| 面積を不均等にする（およそ 7:3） | 補色に近い色を同量で使うと互いに打ち消し合う |
| 色数を増やしすぎない | 16px では1色あたり数ピクセルしか残らない |
| グレースケールで形が残るか確認する | 明度だけで成立していれば、小さくしても色覚特性が異なる人にも崩れない |

| 用途 | 値 |
|---|---|
| 地 / `theme_color` | `#0A0F1F` |
| 光条 | 青 `#2F6BFF` / シアン `#00C2D1` / 橙 `#FF6A00` / 桃 `#FF2D6F` / 紫 `#9B5CFF` |
| 光条の角度 | 10-64° / 78-116° / 132-198° / 214-256° / 274-346°（真上を 0 として時計回り） |
| 光条の内半径 | 215（M の外接半径 約198 より大きく取り、文字に色を掛けない） |
| 書き出し | 192・512（`any`）、512（`maskable`、図案を 0.82 倍して余白を確保）、apple-touch 180、favicon 32/16 |

光条の幅は不揃いにしてある。均等に割ると回る風車に見えて散漫になるため。
16px での実効面積は 地 47.7% / M 12.5% / 紫 14.8% / 青 8.2% / 橙 7.0% / 桃 7.0% / **シアン 2.7%（7px）**。
5条すべてが残るが、最も細いシアンは 7px しかない。光条の角度を変えるときはこの値を再測すること。

`any` と `maskable` はファイルを分ける（`"any maskable"` と1つにまとめない）。

### 12.7 文字ロゴ（Phase 2.5 で追加）

アイコン（12.6）と同じ骨格で「Mieru」を描く。**単線・丸端・丸継ぎ、線幅 34、M の谷は上から66%。**
アイコンの M がそのまま語頭になっているため、並べたときに同じ手で描いたものに見える。

| 項目 | 値 |
|---|---|
| 基準線 | cap 40 / x-height 100 / baseline 240（丸端が ±17 はみ出すので実際の上下端は 23 と 257） |
| 字面の構成 | 直線と正円のみ。曲線は円弧で、ベジェを使わない |
| 色 | **M と e = 青 `#2F6BFF`／u = 橙 `#FF6A00`。** i・r・点は `currentColor` |
| 置き場所 | `src/app/Wordmark.tsx` |

#### 塗り分けの根拠（利用者による命名の由来、2026-09-02）

**M と e で「me」、u で「you」。** 「見える」の目的語は自分と相手であり、
本ツールはその2つのあいだで思考を繋ぐものである、という名前の由来をそのまま色にした。
**色を持つのはこの3文字だけで、点を含む残りは墨のまま**とする。
色の担当を増やすと、由来との対応が読めなくなる。

**この置き方は 12.6 の配色規則を自然に満たす。** M・i・e・r・u と並ぶため、
色の付く字のあいだには必ず墨の字（i と r）が挟まり、
「色どうしを直接隣接させない。あいだに地を挟む」が成立する。
また me が2文字・you が1文字であるため、「面積を不均等にする」も満たす。
**5文字すべてを塗る案はこの2つの規則と逆になる**ため採らなかった。

#### 作りかたの判断

**フォントを使わない。** 文字を `<text>` で置くと環境ごとに別の形が出るのでロゴにならず、
かといって字形を持つためにフォントを1つ足すのは、5文字のために依存を増やすことになる。
直線と円弧だけで組めば、依存も画像ファイルも要らない。

**画像ファイルを書き出さない。** アイコンは PWA が複数寸法の PNG を要求するため生成物が要るが、
文字ロゴの用途は画面内だけである。墨を `currentColor` で置けば明暗どちらの地でも追従し、
明暗2枚を書き出して切り替える仕掛けも要らない。書き出しが要る用途（README など）が
実際に生じてから生成スクリプトを足す。

**アイコンの M と字面の M は別々に持っている。** 共有すると、寸法体系の違う2つ（512 の正方形と
cap 200 の字面）を1つの数値に押し込むことになる。共有すべきは数値ではなく規則
（単線・丸端・谷66%）であり、それをこの節に書いてある。

#### 選定の記録（2026-09-02）

「パキッとメリハリのついたカラフルなロゴ」という要望に対し、16案を実寸で描いて見比べた。
確かめた事実と落とした案を残す。**同じ問いが再燃したときに描き直さないため。**

**白地では鮮やかな5色は沈む。** 実測したコントラスト比は、白地に対してシアン 2.18・橙 2.87・
桃 3.59・紫 3.91・青 4.50。暗地に対しては 4.24〜8.75 で全て通る。
**明暗どちらでも成立する「カラフル」を作るなら、色数を絞るか、明度を地ごとに変えるしかない。**
明度を落とした5色（`#00727E` など）は WCAG は通るが、深緑と焦茶になって鮮やかさが死んだ。
なお採用した橙は白地で 2.87 しかないが、ロゴは WCAG の文字規定の対象外であり、
u1文字だけが担うため語の可読性は青と墨で保たれている。

**「モヤっと」の原因は色ではなく丸端だった。** 線を太らせても丸端のままだと輪郭は立たず、
むしろ丸文字寄りになる。角端（butt / miter）にすれば同じ色のままで輪郭が立つが、
基準線からはみ出さないぶん字面が痩せるため、線幅 44・字間拡大・`e` の終端を浅く切る、
という別の寸法体系が要る。**利用者は最終的に丸端を選んだ**（柔らかさを残す判断）。

| 落とした案 | 理由 |
|---|---|
| 5文字を5色に塗る | 上記2つの配色規則と逆になる。由来とも対応しない |
| 鮮やかな青の板に白抜き | パキッとするが、ツールバーでは押せるボタンに見える |
| アイコンと横並び（ロックアップ） | 17px でアイコンが潰れる |
| 角端・線幅52 | `e` の開口が塞がり、小寸法で `o` に見える |
| 青 × 紫 | 色相が近く、対の関係が読めない |
| 点を you の色にする | 語の左右で色が呼び合って収まりは良いが、由来との対応が薄れる |
