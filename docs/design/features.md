## 7.4 キーボードショートカット

原則4に基づき、全ての主要操作をキーボードで完結させる。

| キー | 動作 | Phase |
|---|---|---|
| `Enter` | 兄弟ノードを追加 | 1 |
| `Tab` | 子ノードを追加 | 1 |
| `Shift+Tab` | 階層を1つ上げる | 1 |
| `Space` / `F2` | 選択ノードを編集 | 1 |
| `Delete` | 選択ノードを部分木ごと削除 | 1 |
| `↑ ↓ ← →` | ノード間を移動 | 1 |
| `Ctrl+↑` / `Ctrl+↓` | 兄弟間で順序を入れ替え | 1 |
| `Ctrl+Shift+↑` | 親子を反転する（選択ノードを親の位置へ） | 2.9 |
| `Ctrl+/` | 折り畳みトグル | 1 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / Redo | 1 |

| `?` / `F1` | キー操作一覧の開閉 | 1 |

**親子の反転（`Ctrl+Shift+↑`）の規則**

反転は `Shift+Tab`（階層を1つ上げる）とは別物である。`Shift+Tab` が自分だけを上げて
後続の兄弟を引き取るのに対し、反転は**親と席を入れ替える**。

| 項目 | 規則 |
|---|---|
| 上がる先 | 親のいた位置。兄弟の中の順番も引き継ぐ |
| 下がった親 | 反転した本人の**先頭の子**になる。末尾に付けると、子が多い親では相手が画面の外へ出て何が起きたか分からない |
| 親の残りの子 | 親に付いていく。反転で枝の中身は動かさない |
| 親がルートのとき | **何もしない。** ルートのラベルはマップの題名であり（6.2）、構造を組み替えたつもりで題名が変わるのを避ける。題名の変更は改名で行う |

**記法の表示（F-26）の規則**

| 場所 | 見せ方 |
|---|---|
| キャンバス | `mind-elixir` の `markdown` オプションへ渡す。**戻り値はそのまま `innerHTML` に入る**ので、渡してよいのは許可リスト方式の変換だけ |
| アウトライン・ノート欄 | トークン列から React の要素として組み立てる。**HTML 文字列を渡す口を増やさない** |
| 編集中 | 生の文字列に戻る。キャンバスは `mind-elixir` が `nodeObj.topic` を `textContent` で入れるため自動的にそうなる |
| ノート欄の切替 | **「読む／書く」の押しボタンにし、既定は「書く」。** この欄は書くために開くものであり、読む状態を既定にすると編集のたびに1回多く押すことになる。**触ると編集に入る方式は採らない** — ノート内のリンクを押す操作と編集開始が同じ動作になり、どちらが起きるか予測できない |

**アウトラインの掴み替え（F-21a）の規則**

**掴むのは行そのものではなく、行頭のグリップである。** 一覧は指で縦に送る面であり、
行を長押しして掴む方式にすると送る操作と競合する。`touch-action` を切る範囲を
グリップだけに限れば、行の他の場所は今までどおり送れる。**掴めることが画面を見て
分かる**利点もある（7.2.1 の「入力手段があることが画面を見ても分からない」への対処）。

| 項目 | 規則 |
|---|---|
| 落とす位置 | 行の上端 30% は前へ、下端 30% は後ろへ、中央 40% はその子にする |
| 帯の広さ | 上下を同じ幅にする。同じ狙い方で行の上下の結果が変わらないようにする |
| 落とせない相手 | 自分自身、自分の子孫（木が輪になる）、ルートの前後（ルートに兄弟は無い）、ルート自身を掴むこと |
| 落とし先の表示 | **色だけで示さない。** 兄弟は辺の線、子は全周の枠と地色で区別する |
| 畳まれた枝の中へ落としたとき | その枝を開く。開かないと落とした行が消え、移動できなかったのか隠れたのかが分からない |
| 中心テーマ | グリップを出さない。掴めない物に掴み手を出さない |

**横断リンク（F-17）と配色（F-24）の解決規則**

| 項目 | 規則 |
|---|---|
| リンクの実体 | ラベル中の `[[対象]]`。`links` はそこから集めた派生であり、ラベルを書き換えたら取り直す |
| 宛先の特定 | 同じマップ内で **ラベルが一致する最初のノード**。同名が複数あっても矢印は1本 |
| 解決できないリンク | 矢印を描かない。書きかけの `[[` に矢印が出ると入力中の画面が騒がしくなる |
| 配色の対象 | 第1階層のブランチのみ。配下は親の色を継ぐ |
| パレット | アイコン（12.6）と同じ5色。ブランチが多ければ巡回する |

**割り当てただけでは操作は使われない。** 一覧を画面から開けるようにし（ツールバーの「キー操作」と `?`）、さらに「フォルダ未選択」「マップ未選択」「枝が0本」の各状態では、その場で次に押すキーを画面に出す。表示と実際の割り当てが食い違わないことは自動テストで担保する（`src/app/shortcuts.ts`）。
