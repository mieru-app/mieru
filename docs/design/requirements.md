## 10. 非機能要件

| 分類 | ID | 要件 | 検証方法 |
|---|---|---|---|
| 性能 | NF-01 | 1000ノードのマップで編集操作が60fpsを維持する | Chrome DevTools Performance で計測 |
| 性能 | NF-02 | マップの初回描画を500ms以内に完了する | 実測 |
| 性能 | NF-03 | 入力停止から800ms後に保存を開始し、200ms以内に完了する | 実測 |
| 信頼性 | NF-10 | 保存処理の中断でファイルが破損しない | 一時ファイル + リネーム方式。異常終了試験 |
| 信頼性 | NF-11 | ラウンドトリップで内容が変化しない | プロパティテスト（6.5） |
| 信頼性 | NF-12 | 競合時にいずれのデータも失われない | 競合シナリオ試験 |
| 可用性 | NF-20 | オフラインでも閲覧・編集ができる | 機内モードで動作確認 |
| 対応環境 | NF-30 | Phase 1: Edge / Chrome 最新2バージョン（Windows 11） | — |
| 対応環境 | NF-31 | Phase 3: 上記に加え Safari / Firefox / iOS Safari / Android Chrome | — |
| 対応環境 | NF-32 | PWAとしてインストールでき、独立ウィンドウで起動する | 実機確認 |
| セキュリティ | NF-40 | Phase 1 は外部通信を一切行わない | ネットワークログで確認 |
| セキュリティ | NF-41 | Phase 3 で他利用者のデータに到達不能である | IAMポリシー（9.2）＋確認試験 |
| セキュリティ | NF-42 | 認証情報を `localStorage` に平文で保持しない | **Phase 2.6 は IndexedDB に平文で保管する。** `localStorage` ではないが同等に平文であり、字義どおりには満たしていない。 権限と期間を絞ることで被害の上限を抑える。根拠と代償は 8.7.2 |
| セキュリティ | NF-43 | **第三者のスクリプト・フォント・解析ツールを読み込まない** | 他人のトークンを預かる以上、外部リソースは持ち出し口になる。**CSP でブラウザに強制させる**（8.6）。方針だけに頼らない |
| セキュリティ | NF-44 | **配信オリジンに Mieru 以外を公開しない** | 8.6。利用者のトークンを守る唯一の防御であり、運用上の約束ではなく要件とする |
| 保守性 | NF-50 | 変換層のテストカバレッジ90%以上 | Vitest coverage |
| 保守性 | NF-51 | UI層は MapStore 以外の永続化APIを直接呼ばない | ESLintのimport制限ルールで機械的に強制 |
