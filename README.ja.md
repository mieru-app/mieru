# Mieru

**日本語** ｜ [English](./README.md)

**AI にインプットするアイデアを、`.md` のまま組み立てるツール**

マインドマップで広げた考えが、そのまま Markdown ファイルとして使用できます。

これが、AIに与えるプロンプトになります。

**➜ [https://mieru-app.github.io/mieru/](https://mieru-app.github.io/mieru/)**
（インストールは不要。ブラウザで動作。）

## こんな困りごとに

**AI に相談したいのに、考えがまとまらない。**
思考が散らかって、結局そのまま長文で投げてしまう。
Mieru ではマインドマップで考えを整理すると、**その形がそのまま AI への入力になります。**
整理と清書が別作業になりません。

**マインドマップを描いても、書き出すと崩れる。**
多くのツールは独自形式で保存し、Markdown 出力は劣化を伴うおまけの機能です。
Mieru は **保存形式が Markdown そのもの**です。書き出しの手順がありません。

**マインドマップツールが他ツールとの互換が悪い。**
Obsidian や VS Code で同じファイルをそのまま扱うことができます。
**Mieru はベンダーロックインを排除する思想です。**
Git に入れれば、考えが変わっていった過程が差分で読めます。

## 使い方

**1. 開く。** リンクを開くだけです。アカウント登録はありません。
➜ [https://mieru-app.github.io/mieru/](https://mieru-app.github.io/mieru/)

**2. とりあえず触る。** 「ゲストモードで試す」で、保存先を決めずに始めることができます。

**3. 保存先を選ぶ。** 2つから選べます。（あとから切り替え可能）

| 保存先 | 置かれるもの | 使える環境 |
|---|---|---|
| **ローカルフォルダ** | 選んだフォルダ直下の `.md` | デスクトップ版 Edge / Chrome |
| **GitHub リポジトリ** | 指定したリポジトリの `.md`（保存はコミットになります） | どの端末でも |

フォルダを選んだ場合、Mieru が触るのは**選んだフォルダの直下にある `.md` だけ**です。

**4. 書く。** `Tab` でツリーの子を、`Enter` でツリーの兄弟を足します。
ショートカット操作は `?` で出ます。スマートフォンでは画面下のボタンで同じことができます。
**保存ボタンはありません。**自動で保存されます。

**5. AI に渡す。** `Ctrl+Shift+C` で、AI が読みやすい形に整えた文章をコピーします。
範囲を選択してコピーすることもできます。

保存される `.md` のイメージはこのようになります。

```markdown
---
title: 新規事業の論点整理
tags: [strategy]
---

# 新規事業の論点整理

- 市場 🌏
  - TAM試算
    既存レポートでは1,200億円。ただし定義が広すぎる疑いがある。
  - 競合の空白地帯
- リスク ⚠️
  - 規制動向 → [[市場]]
```

## 向いている使い方

**AI にインプットする前の思考を整理。**
論点を枝に分けて構造化してからAIに渡すと、返ってくる答えが期待通り具体的になります。
枝ごとに分けてインプットすれば、コンテキストが長すぎて要点がぼやけることもありません。

**プレゼン資料の骨子を作成。**
プレゼンはストーリーラインが大事。全体の論理構成を確認しながら、プレゼン内容を作ることができます。
**メモはキャンバスには出ません**ので、メモにトークスクリプトを書いても、キャンバス全体をスッキリと見渡すことができます。

**Obsidian の vault の中で使用。**
保存先を vault のフォルダにすれば、ツールを横断して編集することができます。
`[[ ]]` のリンクもそのまま書けます。

**移動中の思いつきをメモ。**
保存先を GitHub にすると、スマートフォンからも同じキャンバスを開けます。
帰ってからパソコンで続きが書けます。

## できないこと・できること

### できないこと

| できないこと | 補足 |
|---|---|
| **画像の埋め込み** | Markdown の可搬性を保つため、意図的に対象外です。URL 参照は書けます |
| **自由配置のキャンバス** | 扱えるのはツリー構造だけです。付箋を好きな位置に置く用途には向きません |
| **複数人でのリアルタイム共同編集** | 対象外です。各自が自分のリポジトリを使う形になります |
| **AI による自動マップ生成** | 「自分で考える」ことが目的なので、意図的に外しています |
| **水平線と生の HTML** | `---` と `<div>` は保存時に失われます。警告は出ますが行は戻りません。[既知の課題](./docs/ideas/2026-09-05-blockquote-code.md) |

### できること

| できること | 補足 |
|---|---|
| **図として編集する** | キャンバス表示とアウトライン表示を `Ctrl+E` で切り替えます |
| **保存される `.md` をそのまま見る** | 3つ目の表示です。読み取り専用で、保存されるバイト列と同じものが出ます |
| **表・引用・コードブロック・強調・リンクを見える形で表示する** | ノートの中の記法を描画します。引用とコードはバイト単位でそのまま保たれます |
| **オフラインで使う** | PWA としてインストールできます |
| キーボードだけで完結させる | `?` でショートカット一覧が出ます |
| 過去の版に戻す | ローカルは5分ごと、GitHub はコミットが履歴になります |
| 全文検索とタグでの絞り込み | `Ctrl+F` |
| スマートフォンから編集する | 保存先を GitHub にした場合 |

## 他のツールとの違い

Mieru のメリットは、**図として編集できて、保存形式が Markdown そのもの**である点です。

| | 図として編集 | 保存形式 | アプリ無しで開ける | スマホ | 費用 |
|---|---|---|---|---|---|
| **Mieru** | ✅ | **`.md` そのもの** | ✅ ブラウザだけ | ✅ | 無料 |
| XMind | ✅ 強い | `.xmind`（独自） | ❌ | ✅ | 無料枠は10マップ。Markdown 書き出しは有料 |
| markmap / VS Code の markmap 拡張 | ❌ 表示のみ | `.md` を読む | ❌ VS Code が要る | ❌ | 無料 |
| Obsidian + Mind Map（markmap） | ❌ 表示のみ | `.md` を読む | ❌ Obsidian が要る | ✅ | 無料 |
| Obsidian Canvas | ✅ 自由配置 | **`.canvas`（JSON）** | ❌ | ✅ | 無料 |

（2026-09-05 に確認
[競合調査](./docs/ideas/2026-09-05-stp-and-marketing.md)）

**Mieru を選ぶ理由があるとすれば、次のどれかです。**

- **Obsidian を入れていない端末からも触りたい。** ブラウザだけで開きます
- **Obsidian 公式の Canvas は JSON で保存される。** 図で整理した結果を `.md` で持ちたい
- **編集できるマインドマップ拡張の更新が止まっている。**
- **開いて保存しても中身が変わらないことを保証してほしい。**
  正規化された `.md` の往復がバイト単位で一致することを、
  ランダム生成した木構造で常時テストしています

## よくある疑問

*1. データはどこに保存されますか。誰かに見られますか。*
あなたが指定した場所だけです。**サーバもデータベースもありません。**
Mieru は静的なファイルとして配られるだけで、あなたのファイルが開発者に届くことはありません。
GitHub を保存先にした場合、通信はあなたのブラウザから `api.github.com` へ直接行われます。

*2. GitHub のトークンは何に使われますか。*
あなたが指定したリポジトリの `.md` を読み書きするためだけに使われます。
トークンは**端末のブラウザに保存され、暗号化はされていません。**
そのため **1つのリポジトリだけ・Contents 権限のみ・有効期限つき**で作ることを勧めています。
アプリの中に作り方の手順があります。共用の端末では「この端末に記憶する」を外してください。

*3. それは安全だと言えますか。*
**ブラウザだけで動いて資格情報を扱うアプリは、配信されたコードがその鍵に触れられます。**
これは Mieru に限った話ではありません。だから確かめられる形にしてあります。
コードは全部このリポジトリで読めます。外部の CDN・Web フォント・解析ツールを一切読み込まず、
通信先は CSP で `api.github.com` だけに制限してあります。
**仮にトークンを盗むコードが混入しても、送り先がありません。**
配信元を信用したくない場合は、[自分でホストできます](./CONTRIBUTING.md#自分でホストする)。

*4. オフラインでも使えますか。*
使えます。PWA としてインストールでき、通信がなくても閲覧と編集ができます。
GitHub を保存先にしている場合、保存は通信が戻ってから行われます。

*5. どのブラウザで動きますか。*
GitHub を保存先にするならブラウザは問いません。
パソコンのフォルダを保存先にする場合は Edge / Chrome が必要です
（File System Access API を使うため）。

*6. 他のツールで書いた `.md` を開けますか。*
開けます。**`\*` のようなエスケープ、強調、コード、リンクはそのまま保たれます。**
ただし**保存すると Mieru の書式に整えられます**（箇条書きは `-`、インデントは
半角2つ、frontmatter のキー順は固定）。
上の「できないこと」に挙げた件は**開いて保存した時点で起きます。
大事なファイルは、まず控えを取ってから開いてください。**

*7. Obsidian や VS Code と一緒に使えますか。*
使えます。保存先を vault やリポジトリのフォルダにすれば、同じ `.md` を両方から開けます。
どちらで先に編集しても構いませんが、**Mieru で保存すると書式が整えられます。**
