# 文書の原則

**文書を作る・直す前にこれを読む。**

## 3つの原則

1. **役割ごとに分ける。** 1つの文書に複数の目的を詰めない。「誰が・何のために読むか」で割る
2. **AI 向けは小さく。** コードを読めば分かることを書かない。冗長な文書は判断精度を下げる
3. **正本は1つ。** 同じ情報を2箇所に書かない。他からは参照する

## 置き場所

| 種別 | 場所 | 読者と役割 |
|---|---|---|
| AI 向け設計書 | `docs/design/` | **実装時の正本。** Why と What、横断事項 |
| 層ごとの細則 | `.claude/rules/*.md` | AI 向け。`paths` に合うファイルを触ったときだけ読み込まれる |
| 人間向け解説書 | `docs/human-review/` | 全体像・設計判断・アーキテクチャ |
| 検討の記録 | `docs/ideas/` | **正本ではない。** 着想・比較・実測。日付で始める1件1ファイル |
| 修正指示書 | `docs/reviews/` | レビュー結果に基づく修正指示 |
| ステアリング | `.steering/` | AI の振る舞いの指針（この文書） |
| スキル | `.claude/skills/` | AI が使う再利用可能な手順 |
| 利用者向け | `README.md`（直下） | 誰の何の問題を解決し、どう使い、何が不安か。**開発の話を書かない** |
| 開発者向け | `CONTRIBUTING.md`（直下） | 手元での動かし方、構成、変更の送り方 |

**README は英語が正本、`README.ja.md` が日本語版。** 他は全て日本語。
狙う読者の情報源が英語であるため（`docs/ideas/2026-09-05-stp-and-marketing.md`）。
**併記にしない。** 1つの文書に2言語を入れると、片方だけ古くなる。
**README を直したら両方直す。** 片方だけ直すくらいなら、日本語版に
「英語版が新しい」と書く方がよい。

直下の2つは GitHub が特別扱いする（README はトップに表示、CONTRIBUTING は Issue と PR で案内される）。

## 何を書き、何を書かないか

**AI 向け設計書（`docs/design/`）**

- 書く: **Why**（なぜそうするか）と **What**（何を実現するか）、実装時に迷う**横断事項**
  （命名規則、層間の依存、エラー方針、共通の制約）
- 書かない: **How**（コードが語る）、個別ファイルを読めば分かること

**人間向け解説書（`docs/human-review/`）**

- 書く: 多くのファイルを読まないと見えない**骨組みと意図**
  （全体像・構成図、採った判断と捨てた選択肢、レイヤーとデータフロー、中核アルゴリズムの考え方）

## 正本の割り当て

| 情報 | 正本 |
|---|---|
| **いまどこにいるか・次に何をするか** | `docs/human-review/roadmap.md` |
| 設計原則・不変条件 | `docs/design/principles.md` |
| 機能一覧（F-xx）とキー割り当て | `docs/design/features.md` |
| 非機能要件（NF-xx） | `docs/design/requirements.md` |
| コマンド一覧 | `CLAUDE.md`（開発者向けの抜粋を `CONTRIBUTING.md` に） |

**現在地を README や CLAUDE.md に書かない。** 必ずずれる。
2026-09-05 の刷新前は3箇所に書かれ、3つとも違う Phase を指していた。

## 決まり

- 新規作成の前に、既存カテゴリのどこに属するかを確認する
- 実装と `docs/design/` が乖離したら、**`docs/design/` の更新を優先する**
- `ideas/` で確定した内容は `docs/design/` へ移す。`ideas/` は記録として残す
- **節番号で参照しない。** 文書名か安定 ID（`F-xx` `NF-xx` `R-xx` `PR-xx`）を使う。
  章番号は動く（2026-09-05 の分割で 92 箇所が迷子になりかけた）
- AI 向け文書が肥大化したら削れる内容を探す。目安は1ファイル 200 行

## 検査

`npm run lint` が `scripts/check-docs.mjs` を通し、2つを弾く。

- 壊れた相対リンク
- ロードマップ以外での Phase の完了宣言（正本の重複）
