# Should we self-host our docs?

- Why now 🤔
  - Vendor price doubled at renewal
  - Search returns last quarter's pages
- Options
  - Stay on the SaaS
    Cheapest in effort. We keep paying for a search nobody trusts.
  - Markdown in the repo
    Docs sit next to the code and get reviewed in the same pull request.
  - Self-hosted wiki
    One more server to patch, back up and forget about.
- What actually decides it
  - How often the docs change
  - Who is allowed to edit them
