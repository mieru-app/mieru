# Should we use Mieru?

- Why we're on the fence 🤔
  - Our notes live inside someone else's app
    Notes are an asset. Break out of vendor lock-in early.
  - Bullet lists make ideas hard to rearrange
    Seeing them as a diagram makes them easier to sort out.
- What can it do?
  - Organize AI input and output visually
    Lay the ideas out as a picture.
  - No vendor lock-in
    No database and no account. The diagram is the .md itself.
  - Edit as a mind map
    Drag a branch and the line order in the file moves with it.
- What decides it
  - Whether we already work in .md
  - Whether other people edit the same files
