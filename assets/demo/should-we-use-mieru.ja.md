# Mieru を使うべきか

- なぜ迷っているか 🤔
  - メモが他社のアプリの中にある
    メモは資産。早めにベンダーロックインは回避しよう。
  - 箇条書きではアイデアを組み替えにくい
    図で可視化するとアイデアを整理しやすい。
- 何ができるのか？
  - AIとのインプット / アウトプットを視覚的に整理
    アイデアを視覚的に整理できる。
  - ベンダーロックインの回避
    データベースもアカウントも無い。図が.mdそのものである。
  - マインドマップを編集
    枝を掴んで動かすと、ファイルの行順もそのまま動く。
- 何で決まるか
  - .mdファイルを使っているか
  - 同じファイルを他の人も編集するか
