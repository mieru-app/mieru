# MindDeck（仮称）

考えを整理するためのマインドマップツール。整理した内容をそのままAIへの入力ドキュメントとして使えることを目的とする。

**中核となる設計思想: Markdown は出力形式ではなく保存形式である。**
編集結果は常に人間可読な `.md` ファイルとして存在し、AIへの入力は「そのファイルを渡す」だけで完了する。
