# Mieru

**考えを整理して、そのまま AI に渡せるマインドマップ。**
保存されるのは独自形式ではなく、ふつうの Markdown ファイルです。

**➜ [https://mieru-app.github.io/mieru/](https://mieru-app.github.io/mieru/)**
（インストール不要。ブラウザで開けばすぐ使えます）

---

## こんな困りごとに

**AI に相談したいのに、考えがまとまっていない。**
書き出すほど散らかって、結局そのまま長文で投げてしまう。
Mieru では枝を広げて考えを整理すると、**その形がそのまま AI への入力になります。**
整理と清書が別作業になりません。

**マインドマップを描いても、書き出すと崩れる。**
多くのツールは独自形式で保存し、Markdown 出力は劣化を伴うおまけの機能です。
Mieru は **Markdown が保存形式そのもの**です。書き出しの手順がありません。

**ノートとマップを二重に管理している。**
保存されるのは `.md` ファイルなので、Obsidian や VS Code で同じファイルをそのまま開けます。
Git に入れれば、考えが変わっていった過程が差分で読めます。

**このアプリが将来なくなったら困る。**
残るのは `.md` ファイルです。**Mieru が消えてもデータは無傷で、他のツールで読めます。**

## 使い方

**1. 開く。** 上のリンクを開くだけです。アカウント登録はありません。

**2. 保存先を選ぶ。** 2つから選べます。あとから切り替えられます。

| 保存先 | 置かれるもの | 使える環境 |
|---|---|---|
| **このパソコンのフォルダ** | 選んだフォルダ直下の `.md` | デスクトップ版 Edge / Chrome |
| **GitHub のリポジトリ** | 指定したリポジトリの `.md`（保存はコミットになります） | どの端末でも |

**3. 書く。** `Tab` で子を、`Enter` で兄弟を足します。それだけで形になります。
キーの一覧は `?` で出ます。スマートフォンでは画面下のボタンで同じことができます。
**保存ボタンはありません。**打つのをやめると自動で保存されます。

**4. AI に渡す。** `Ctrl+Shift+C` で、AI が読みやすい形に整えた文章をコピーします。
枝を選んでから押せば、その部分だけをコピーできます。

書いたものはこんな `.md` になります。

```markdown
---
title: 新規事業の論点整理
tags: [strategy]
---

# 新規事業の論点整理

- 市場 🌏
  - TAM試算
    既存レポートでは1,200億円。ただし定義が広すぎる疑いがある。
  - 競合の空白地帯
- リスク ⚠️
  - 規制動向 → [[市場]]
```

## 向いている使い方

**AI に投げる前の下ごしらえ。**
論点を枝に分けてから「この構造でたたき台を書いて」と渡すと、返ってくる答えが具体的になります。
枝ごとに分けて投げれば、長すぎて要点がぼやけることもありません。

**読書メモ・学習メモ。**
章立てを枝にして、気づきをノートに書き足していきます。
**ノートはキャンバスには出ません**ので、地図は軽いまま中身を厚くできます。

**Obsidian の vault の中で使う。**
保存先を vault のフォルダにすれば、マップとノートが同じ場所に並びます。
`[[ ]]` のリンクもそのまま書けます。

**移動中の思いつきを溜める。**
保存先を GitHub にしておくと、スマートフォンからも同じマップを開けます。
帰ってからパソコンで続きを書けます。

## よくある疑問

**データはどこに保存されますか。誰かに見られますか。**
あなたが指定した場所だけです。**サーバもデータベースもありません。**
Mieru は静的なファイルとして配られるだけで、あなたのマップが開発者に届くことはありません。
GitHub を保存先にした場合、通信はあなたのブラウザから `api.github.com` へ直接行われます。

**GitHub のトークンは何に使われますか。**
あなたが指定したリポジトリの `.md` を読み書きするためだけに使われます。
トークンは**この端末のブラウザに保存され、暗号化はされていません。**
そのため **1つのリポジトリだけ・Contents 権限のみ・有効期限つき**で作ることを勧めています。
アプリの中に作り方の手順があります。共用の端末では「この端末に記憶する」を外してください。

**それは安全だと言えますか。**
**ブラウザだけで動いて資格情報を扱うアプリは、配信されたコードがその鍵に触れられます。**
これは Mieru に限った話ではありません。だから確かめられる形にしてあります。
コードは全部このリポジトリで読めます。外部の CDN・Web フォント・解析ツールを一切読み込まず、
通信先は CSP で `api.github.com` だけに制限してあります。
**仮にトークンを盗むコードが混入しても、送り先がありません。**
配信元を信用したくない場合は、[自分でホストできます](./CONTRIBUTING.md#自分でホストする)。

**オフラインでも使えますか。**
使えます。PWA としてインストールでき、通信がなくても閲覧と編集ができます。
GitHub を保存先にしている場合、保存は通信が戻ってから行われます。

**どのブラウザで動きますか。**
GitHub を保存先にするならブラウザは問いません。
パソコンのフォルダを保存先にする場合は Edge / Chrome が必要です
（File System Access API を使うため）。

**他のツールで書いた `.md` を開けますか。**
開けます。ただし**保存すると Mieru の書式に整えられます。**
また、`\*` のように記号を打ち消して書いた箇所は、いま**そのままでは戻りません**
（[既知の課題](./docs/ideas/2026-09-04-escape-roundtrip.md)）。
大事なファイルは、まず控えを取ってから開いてください。

**表や強調は使えますか。**
使えます。ノートの中の表・強調・コード・リンクはそのまま見える形で表示されます。
**引用（`>`）とコードブロックだけは、いまのところ保存時に失われます。**

**共同編集はできますか。**
できません。意図的に対象外にしています。
複数人で使う場合は、各自が自分のリポジトリを使う形になります。
